# Social Media Usage Analysis System

## Project Overview
The Social Media Usage Analysis System is a Python-based data analysis project that analyzes social media usage patterns through an interactive dashboard.

The project helps understand platform preferences, daily usage time, sleep duration, and productivity scores using data visualization and statistical analysis.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Streamlit

## Features
1. Social media usage analysis.
2. Platform-wise usage comparison.
3. Interactive dashboard.
4. Average daily usage calculation.
5. Sleep duration analysis.
6. Productivity analysis.
7. Interactive platform filters.
8. Automated analytical insights.
9. Dataset download functionality.

## Installation and Execution

### 1. Clone the repository
```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Open the project folder
```bash
cd Social-Media-Usage-Analysis
```

### 3. Create virtual environment
```bash
python3 -m venv venv
```

### 4. Activate environment
```bash
source venv/bin/activate
```

### 5. Install dependencies
```bash
pip install -r requirements.txt
```

### 6. Run the dashboard
```bash
streamlit run app.py
```
